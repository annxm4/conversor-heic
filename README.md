# Conversor HEIC para JPEG

Converte fotos do iPhone (.heic / .heif) para JPEG direto no navegador, em lote e sem limite.
As fotos não são enviadas para nenhum servidor: a conversão acontece no próprio computador ou celular.

**Como usar:** abra o site, escolha ou arraste as fotos, espere a conversão e clique em **Baixar todas (.zip)**.

Site: https://annxm4.github.io/conversor-heic/
